# Herder

Monorepo: the macOS app in `apps/herder` and its supporting packages in `packages/*`. Each has its own `AGENTS.md`. Read the one for the area you're working in.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `kurtschwarz/herder`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: a root `GLOSSARY-MAP.md` points to one `GLOSSARY.md` per app or package. See `docs/agents/domain.md`.
